## Setup

### 1. Upload ke cPanel
Upload semua fail ke `public_html/` atau subdomain.

### 2. Buat Database MySQL di cPanel
```
Database Name: ckm_admin
Username: (auto-generated by cPanel)
Password: (set your own)
```

### 3. Konfigurasi
Salin `config.example.php` sebagai `config.php` dan isi:
```php
return [
    'SENDGRID_API_KEY'    => 'SG.xxx',
    'SENDGRID_FROM_EMAIL' => 'jom@cucikarpetmasjid.com',
    'ENQUIRY_TO_EMAIL'    => 'jom@cucikarpetmasjid.com',
    'DB_HOST' => 'localhost',
    'DB_NAME' => 'ckm_admin',
    'DB_USER' => 'your_db_user',
    'DB_PASS' => 'your_db_pass',
];
```

### 4. Run Setup
Buka: `https://cucikarpetmasjid.com/admin/setup.php`
- Creates all database tables
- Creates default admin user
- **DELETE setup.php selepas selesai!**

### 5. Log Masuk Admin
URL: `https://cucikarpetmasjid.com/admin/`
```
Email: admin@cucikarpetmasjid.com
Password: admin123
```
**Tukar kata laluan di Settings selepas log masuk!**

## Features

### Enquiry Management
- Form dari website auto-save ke database
- Auto-generate ref no: CKM-YYYYMMDD-XXX
- Status: Baru → Dihubungi → Dipetik → Menang/Hilang
- Nota dalaman admin
- Butang WhatsApp terus ke customer

### Quotation System
- Create quotation dari enquiry (auto-fill data)
- Multiple line items dengan auto-calculation
- Tax rate & discount support
- Status: Draf → Dihantar → Diterima/Ditolak
- Print/PDF ready (navy/gold themed)
- Auto-generate quote no: Q-YYYYMMDD-XXX

### Invoice System
- Create invoice dari quotation (auto-copy semua data)
- Standalone invoice juga boleh
- Payment tracking — rekod partial/full payment
- Auto update status: unpaid → partial → paid
- Payment method & reference tracking
- Print/PDF ready
- Auto-generate invoice no: INV-YYYYMMDD-XXX

### Settings
- Company info (name, email, phone, address)
- Tax rate configuration
- Currency, quote/invoice prefixes
- Change admin password
